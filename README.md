## ¿Qué hace?

Una calculadora de consola que resuelve operaciones matemáticas comunes:

- Cálculo de pendiente
- Regla de tres
- Perímetro y área de: triángulos, rectángulos, círculos, paralelogramos, trapecios y cuadrados
- Volumen de: prisma base rectangular, cubos, prisma base cuadrada, cilindros y pirámide base cuadrada

## ¿Cómo usarlo?

Requiere **Python 3**.

```bash
python Calculator.py
```

Seguí las instrucciones en pantalla: ingresá el número de la operación y presioná `[ENTER]`.
